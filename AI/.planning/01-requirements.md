# InterviewAI — 요구사항 (MoSCoW)

## Must Have (핵심 기능)

| # | 요구사항 | 근거 |
|---|----------|------|
| M1 | 음성 녹음 및 STT 변환 (Whisper API) | 음성 기반 면접의 핵심 |
| M2 | AI 피드백 생성 (Claude claude-sonnet-4-6) | 차별화된 핵심 가치 |
| M3 | 직군별 면접 질문 제공 (직무/인성) | 실전 맞춤 연습 |
| M4 | 질문 TTS 자동 재생 (flutter_tts) | 실전 면접 분위기 조성 |
| M5 | 면접 결과 화면 (점수 + 강점/약점) | 즉각적인 피드백 확인 |
| M6 | 직종 자유 입력 + 자동완성 | 모든 직군 대응 |
| M7 | 질문 수 선택 (3/5/7/10문제) | 사용자 맞춤 세션 |
| M8 | 마이크 권한 처리 및 에러 핸들링 | 기본 UX 보장 |

| S4 | 취약 영역 자동 분석 (키워드 추출) | 학습 방향 제시 |
