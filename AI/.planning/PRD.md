## 2. WHAT — 무엇을 만드는가

### 2.1 제품 정의

InterviewAI는 **음성 기반 AI 면접 시뮬레이션 Flutter 모바일 앱**이다.
사용자가 음성으로 답변하면 Whisper API가 텍스트로 변환하고,
Claude API가 STAR 구조·논리성·구체성을 분석해 즉각 피드백을 제공한다.

### 2.2 핵심 기능 목록 (MoSCoW)

#### ✅ Must Have — 없으면 앱이 아님

| ID | 기능 | 설명 | 검증 기준 |
|----|------|------|-----------|
| M-01 | 직군/유형 설정 | 개발자·기획자·디자이너 × 기술·인성 선택 | 6가지 조합 정상 라우팅 |
| M-02 | 질문 TTS 출력 | 면접 질문을 flutter_tts로 음성 재생 | 한국어 자연스럽게 읽힘 |
| M-03 | 음성 녹음 | flutter_sound로 마이크 입력 캡처 | 30초 이상 녹음 가능 |
| M-04 | STT 변환 | 오디오 → Whisper API → 한국어 텍스트 | 정확도 90% 이상 (5문장 기준) |

## 5. WHY — 왜 만드는가

### 5.1 문제 정의

| 문제 | 현재 해결책 | 한계 |
|------|------------|------|
| 혼자 연습 불가 | 스터디 파트너 | 시간·장소 조율 필요, 공급 부족 |
| 피드백 없음 | 유료 코칭 | 1회 3~10만 원, 접근성 낮음 |
| 실전 감각 부족 | 유튜브·책 | 단방향, 개인화 없음 |

### 5.2 AI가 필수인 이유

규칙 기반으로 면접 답변을 평가하려면 모든 직군 × 질문 × 답변 조합을 사전 정의해야 한다.
한국어 맥락·뉘앙스를 규칙으로 표현하는 것은 불가능하며,
STAR 구조 여부·구체성·논리 흐름은 LLM만 종합 평가할 수 있다.

> **→ Claude API가 핵심 가치 생성의 유일한 방법이다.**

### 5.3 시장 기회

- 국내 연간 취업 지원자: 약 50만 명 (통계청 2024)
- 기존 AI 면접 앱의 한계: 질문 고정형, 피드백 단순
- InterviewAI 차별점: 음성 중심 + 즉각 맥락 피드백 + 성장 트래킹

## 6. HOW — 어떻게 만드는가

### 6.1 기술 스택

| 영역 | 기술 | 선택 이유 |
|------|------|-----------|
| 프론트엔드 | Flutter + Dart | 단일 코드베이스, 2인 개발 효율 극대화 |
| 상태관리 | Riverpod 2.x | Flutter 표준, Provider 개선판, 테스트 용이 |
| 음성 녹음 | flutter_sound | 크로스플랫폼 오디오 캡처, m4a 포맷 지원 |
| STT | OpenAI Whisper API | 한국어 인식 최상급, 별도 학습 불필요 |
| AI 피드백 | Claude claude-sonnet-4-6 | 긴 답변 처리, 한국어 품질, JSON 응답 강제 |
| TTS | flutter_tts | 네이티브 래핑, 추가 API 비용 없음 |
| 인증 | Firebase Auth | 즉시 사용 가능, Google 로그인 지원 |
| DB | Cloud Firestore | 실시간 동기화, 서버 구축 불필요 |
| CI/CD | GitHub Actions | 자동 빌드, APK 아티팩트 생성 |
| 개발 도구 | VS Code + Claude Code | AI 에이전트 기반 Vibe Coding |

### 6.2 핵심 데이터 흐름

```
[1] 사용자 음성 녹음 (flutter_sound → .m4a)
      ↓
[2] 오디오 파일 → Whisper API → 한국어 텍스트
      ↓
[3] {질문 + 텍스트 + 직군 컨텍스트} → Claude API
      ↓
[4] JSON 피드백 파싱
    {
      "score": 78,
      "strengths": ["STAR 구조 명확"],
      "improvements": ["수치 근거 부족"],
      "summary": "논리는 좋으나 구체성 보완 필요"
    }
      ↓
[5] UI 렌더링 + Firestore 저장
```

### 6.3 Claude 피드백 프롬프트 구조

```
System: 당신은 [직군] 면접관입니다. 다음 기준으로 평가하세요:
  - STAR 구조 (Situation·Task·Action·Result)
  - 구체성 (수치, 사례 포함 여부)
  - 논리 흐름
  - 직군 적합성

User: 질문: [질문 텍스트]
     답변: [Whisper 변환 텍스트]

     다음 JSON 형식으로만 응답하세요:
     {"score": int, "strengths": [], "improvements": [], "summary": ""}
```

### 6.4 화면 구성

| 화면 | 주요 컴포넌트 | 사용 API |
|------|-------------|---------|
| 온보딩/설정 | 직군 선택, 면접 유형, 난이도 슬라이더 | — |
| 면접 진행 (핵심) | 질문 텍스트 + TTS 버튼, 녹음 버튼, 파형, 변환 텍스트 | Whisper, flutter_tts |

| 히스토리 | 세션 목록, 주차별 점수 그래프, 취약 태그 | Firestore |
